# Lesson 00: Course Setup

[Course home](../../README.md) · [Lesson 01: AI Foundations →](../01-ai-foundations/README.md)

> How the course works, the four tracks, and the free accounts you need.

**Tracks:** Leadership, Architecture, Engineering, Research · **Sources:** official OpenAI and Anthropic material, verified November 2026

## In this lesson

- Pick the track that matches your role
- Set up free OpenAI and Anthropic developer accounts
- Know where each provider publishes its official material

## Why it matters

OpenAI and Anthropic each publish courses, docs, cookbooks and research, but the material is spread across a dozen sites. This course puts it in one order so you can learn step by step. Every link points to an official source, so you can trust what you read and cite it at work.

## Learn from OpenAI

| Resource | Type | Level | What you get |
|---|---|---|---|
| [OpenAI Academy](https://www.openai.com/academy) | Hub | Beginner | 14 free courses across four pathways |
| [OpenAI developer docs](https://developers.openai.com/topics/agents) | Hub | Beginner | API, Agents SDK, Codex and Apps SDK docs |
| [OpenAI Cookbook](https://developers.openai.com/cookbook) | Hub | Beginner | Runnable notebooks by topic |

## Learn from Anthropic

| Resource | Type | Level | What you get |
|---|---|---|---|
| [Anthropic Academy](https://anthropic.skilljar.com/) | Hub | Beginner | 22 free courses for workers, builders and leaders |
| [Claude Platform docs](https://platform.claude.com/docs/en/build-with-claude/overview) | Hub | Beginner | Every model capability and tool in one table |
| [Claude Cookbooks](https://github.com/anthropics/claude-cookbooks) | Repo | Beginner | Notebooks for tool use, RAG, agents and more |

## Try it

1. Open the interactive learning path and choose a track.
2. Create a developer account with each provider and generate one API key.
3. Bookmark both academies; you will return to them in several lessons.

## Check yourself

1. Which of the four tracks fits your role today, and which one would you take next?
2. Where would you look first for a runnable code example from each provider?
3. Why does it matter that every resource in this course comes from an official source?
