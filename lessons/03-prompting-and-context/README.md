> Write instructions models follow reliably, and give them the right context.

**Tracks:** AI at Work, Management, AI Leadership, Engineering · **Sources:** official OpenAI and Anthropic material, verified November 2026

## In this lesson

- Structure a prompt with role, task, context, format and examples
- Explain why context matters more than clever wording
- Turn a one-off prompt into a reusable template

## Why it matters

Most poor AI output comes from vague instructions or missing context. Learning to brief a model well is the cheapest quality gain available. The same skill carries over directly to agents, where the brief becomes a system prompt.

## Try it

1. Take the weekly task from Lesson 2 and write a prompt with five labeled parts: role, task, context, output format, one example.
2. Run it three times and compare the outputs for consistency.
3. Save the version that works as a template with placeholders.

## Check yourself

1. Which part of a prompt most often fixes inconsistent output?
2. When should you add an example instead of more instructions?
3. How does a reusable template reduce review effort for a team?
