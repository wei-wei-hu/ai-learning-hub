## In this lesson

- Use an AI assistant for research, writing and analysis with your own files
- Hand a multi-step task to an agent feature and review what it did
- Build a weekly routine around the tasks AI does well for you

## Why it matters

Most people meet AI through ChatGPT or Claude, not through code. The real value comes from moving past one-off questions to repeatable tasks with your own files and a clear review step. Both academies built their most popular courses around this kind of everyday work.

## Which approach should you explore?

The skills are the same on both sides, so start with the assistant your organization already licenses, and check its data-handling requirements and available integrations before you rely on it. OpenAI Academy teaches this as repeatable workflows with review points. Anthropic's courses start from Claude's own features and add versions for specific sectors, which helps if you work in a small business, a nonprofit or education.

*These are practical starting recommendations based on the resources in this lesson. Neither provider has been benchmarked here, and studying both is often worthwhile.*

## Try it

1. Pick three tasks you do every week, such as a summary, a draft and a small analysis.
2. Do each one with an AI assistant using your own files, then do the longest one with an agent feature such as ChatGPT's agent mode or Claude Cowork.
3. Note the time each took and every correction you made, and keep the version that saved the most time for next week.

## Check yourself

1. Which task gave the best result, and what made it different from the others?
2. What did you have to correct, and what does that tell you about where review is needed?
3. Which of your tasks would you never hand off fully, and why?
