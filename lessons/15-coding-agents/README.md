**Tracks:** AI Leadership, Engineering · **Sources:** official OpenAI and Anthropic material, verified November 2026

## In this lesson

- Set up Codex and Claude Code on a small project
- Write project guidance in AGENTS.md or CLAUDE.md
- Review agent changes with tests and diffs before merging

## Why it matters

Coding agents are where agentic AI is most mature today. OpenAI's harness engineering post and Anthropic's best practices both describe engineers moving from typing code to directing and checking it. Leaders should understand this shift even if they never write code.

## Which approach should you explore?

Codex and Claude Code cover the same job, and both run from the terminal and in an editor. Preference here depends heavily on your codebase and how your team reviews changes. Give both the same real task from your own repository, then compare correctness, test results, maintainability, review effort and cost.

*These are practical starting recommendations based on the resources in this lesson. Neither provider has been benchmarked here, and studying both is often worthwhile.*

## Try it

1. Pick a small repo and write a one-page AGENTS.md or CLAUDE.md.
2. Ask each agent to add one feature with tests.
3. Review both diffs and record what you had to correct.

## Check yourself

1. What belongs in a project guidance file?
2. Why are tests the most important input you can give a coding agent?
3. What changes for an engineering manager when agents write most of the code?
